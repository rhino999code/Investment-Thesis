## 리포트 구조 (v2.0)

0. Executive Summary — 5대 메가트렌드, 12년 로드맵, Phase별 핵심 카테고리, 결론 8가지
1. 프레임워크 — 메가 → 매크로 → 섹터 → 카테고리 → 마이크로 계층, 4개 Phase, 평가 기준
2. 5대 메가트렌드 선정 — 12개 후보 평가, 사용자 제안의 배치
3. M1 컴퓨트–에너지 넥서스
4. M2 노동의 자본 대체
5. M3 지정학적 파편화와 재무장
6. M4 물리적 위험의 상시화
7. M5 재정 지배와 분배 정치 (정부 의존·포퓰리즘 결론 포함)
8. 참고 트렌드 — A. 주의력 경제와 인식론적 위기, B. 인구 구조 전환, C. 통화 체제의 신뢰 이완
9. 트렌드 간 상호작용과 시나리오
10. 12년 통합 로드맵 (거시 가정, 이벤트 캘린더)
11. Phase별 흥하는 카테고리 통합 목록
12. 자본시장 구조 — 스타트업, 대형 M&A, 중소·중견 M&A, 한국
13. 포트폴리오 구성 원칙
14. 시그널과 반증 조건
15. 결론
- 부록 A. 트렌드–본문 색인 / 부록 B. 주요 출처

각 메가트렌드 장은 정의·근거 → 매크로 동인 → Phase별 전개 → 드릴다운(섹터·카테고리·마이크로, Phase I~IV 등급, 규제 노출) → 리스크·반증 순서로 구성된다.
