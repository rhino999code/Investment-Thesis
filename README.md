## 리포트 구조 (v3.0)

- 이 리포트를 읽는 법 — 이름 규칙, 표 기호, 정치 리스크 열의 뜻
- 요약 — 5대 매크로 메가트렌드, 12년 로드맵, 시기별 핵심 카테고리, 핵심 결론 8가지
1. 프레임워크 — 다섯 층위(큰 흐름 → 핵심 변수 → 산업 → 카테고리 → 세부 항목), 4개 시기, 평가 기준
2. 5대 트렌드는 어떻게 골랐나 — 후보 12개 채점, 사용자 제안의 배치
3. 매크로 메가트렌드 1: AI 연산 수요와 에너지 제약
4. 매크로 메가트렌드 2: 노동을 대체하는 자본
5. 매크로 메가트렌드 3: 쪼개지는 세계와 재무장
6. 매크로 메가트렌드 4: 일상이 된 물리적 위험
7. 매크로 메가트렌드 5: 재정의 한계와 분배의 정치 (정부 의존·포퓰리즘 결론 포함)
8. 참고 트렌드 — A. 주의력 경제와 진실의 위기, B. 인구 구조의 전환, C. 화폐 신뢰의 이완
9. 트렌드는 서로를 키운다 — 다섯 개의 증폭 고리, 세 가지 시나리오
10. 12년 통합 로드맵 — 시기별 거시 가정, 이벤트 캘린더
11. 시기별로 흥하는 카테고리 통합 목록 (1기~4기, 12년 구조 성장·쇠퇴)
12. 자본시장의 구조 — 스타트업, 대형 M&A, 중소·중견 M&A, 한국
13. 포트폴리오 구성 원칙
14. 시그널과 반증 조건
15. 결론
- 부록 A. 어디에 무엇이 있나 / 부록 B. 주요 출처

각 메가트렌드 장은 핵심 메시지 → 무슨 일이 일어나고 있나 → 핵심 변수 전망 → 시기별 전개 → 카테고리 표(산업·카테고리·세부 항목, 1~4기 등급, 정치 리스크) → 이 트렌드가 틀리는 조건 순서다.
